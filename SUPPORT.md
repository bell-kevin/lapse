# Getting Help

## Documentation

Start with the [README](README.md) for installation, command usage, storage
format, and current limitations.

## Bugs, feature requests, and questions

Use the [GitHub issue tracker](https://github.com/bell-kevin/lapse/issues).
Before opening an issue, search existing reports. Include:

- your operating system and `lapse --version` output;
- how `lapse` was installed or built;
- the command you ran and the complete error message;
- a minimal reproduction that does not contain private data.

## Security issues

Do not disclose a suspected vulnerability in a public issue. Follow the private
reporting instructions in [SECURITY.md](SECURITY.md).
